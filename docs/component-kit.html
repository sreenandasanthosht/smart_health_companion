Design System · v1

Smart Health Companion

The single source of truth for every screen in the platform. A soft sage canvas, white cards, one deep green accent, dark readable text, generous whitespace, and a status language that never depends on colour alone. Every class shown here already exists in carenest.css — the templates need no markup changes to adopt it.

The five states from the brief. Each one carries an icon, a word and a colour, so the meaning survives greyscale printing, a dim screen, and colour-blind vision. Never ship a status that is only a coloured dot.

The order the brief asks for, top to bottom: welcome, today’s summary, the four numbers that matter, then reminders and activity, then quick actions. Nothing competes for attention; there is one accent block and a lot of white.

12 · Rules for every new page

Layout

  • One .page-head per page: role chip, H1, one-line description.
  • Never more than six panels on a screen. If you need more, split the page.
  • Most important information first, top-left. Detail below the fold.
  • Whitespace is the layout tool, not borders and boxes inside boxes.

Language

  • Write to an adult who is not a clinician. “Blood pressure”, not “BP”.
  • Errors name the fix. Success messages say what was saved and who can see it.
  • No jargon in a label. Put the explanation in .hint, not in the label.

Accessibility floor

  • Body text never below 16px; meta text never below 12.5px.
  • Every interactive target at least 44×44px.
  • Every field has a <label for>. Icon-only buttons get .sr-only text.
  • Every page starts with a skip link and one <h1>.
  • Status is never colour alone — icon and word as well.
  • Focus is always visible. Do not remove the outline.

Restraint

  • No gradients except the one hero block. No glows, no drop shadows on text.
  • One accent colour. Semantic colours only carry meaning, never decoration.
  • No illustration unless it explains something.
