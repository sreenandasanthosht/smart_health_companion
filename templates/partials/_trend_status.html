{% comment %} Renders a vitals status as icon + word + colour -- never colour alone. Include it with the series dict as "s", for example series.bp or series.heart_rate. Note: Django {# #} comments are SINGLE-LINE only. A multi-line one is not recognised as a comment at all -- its contents render as literal text, and any tag inside it is executed. Use {% templatetag openblock %} comment blocks instead. {% endcomment %} {% if s.status == 'Normal' %}Normal {% elif s.status == 'Elevated' %}A little high {% elif s.status == 'High' %}High {% elif s.status == 'No data' %}Nothing logged {% endif %}
